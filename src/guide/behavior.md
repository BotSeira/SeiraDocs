# 排队、上下文与文件

## 异步任务与排队提示

图片、外部数据和回放请求通常不会在解析指令时立即完成。
Seira 会先估算同类型任务的等待时间，再异步执行请求。

普通异步任务可能先回复：

> 请求已加入队列，预计等待时间 X 秒。

之后再发送图片、Markdown、语音或其他最终结果。

回放任务在提交到后端后还要等待渲染，进度可通过 `/rstat` 查询。

## 群成员上下文

Seira 收到群消息时，会记录“群—用户”关系。只有已经绑定 osu! UID 的成员才能进入群排行或群好友筛选。

- `/lb` 无参数：群聊中使用本群已记录的绑定成员；私聊中只使用自己。
- `/f`：群聊中把好友关系过滤为当前群成员；私聊中显示完整结果。
- `/rsc`：默认使用本群已记录的绑定成员。
- `/clearhistory`：删除发送者自己的群成员关系，不会解绑 osu! 账号。

群关联来自机器人实际收到的消息。刚加入但从未与机器人交互的成员，可能暂时不会进入被记录。

## 私聊上传回放

当前代码只在 QQ 私聊附件事件中处理回放：

- 文件类型必须是普通文件。
- 文件名必须以 `.osr` 结尾。
- 文件大小不得超过 128 KiB。
- Seira 下载附件后会回复识别到的回放信息。

文件过大、下载失败或上游拒绝时会收到错误消息。

## 账号与 Token

`/bind` 不只是保存 osu! UID，也会保存用于好友与多人房间功能的 OAuth Token。若 Token 无法刷新，`/f`、`/fall` 或 `/mp` 会要求先 `/unbind` 再 `/bind`。

`/unbind` 会删除当前 QQ 用户的绑定关系。重新绑定可修复错误绑定或旧 Token 数据不兼容的问题。

## 错误类型

| 提示                 | 常见原因                                       |
|----------------------|------------------------------------------------|
| 未知指令             | 指令未注册，或调试模式关闭时使用了调试指令     |
| 请求处理失败         | oStella 返回错误、网络异常或结果格式不符合预期 |
| oStella API 无法连接 | 上游服务不可达或连接被关闭                     |
| 无法解析时间范围     | `/r` 时间范围格式错误                          |
| 未找到渲染请求       | 当前用户没有最近渲染任务，且未提供任务 ID      |

遇到稳定复现的问题，可在 [Seira Issues](https://github.com/BotSeira/SeiraCore/issues) 提交反馈，
并附上指令、使用场景、错误提示和大致时间；不要公开配置密钥、OAuth Token 或数据库内容。
