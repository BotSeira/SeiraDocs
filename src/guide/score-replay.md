# 成绩与回放

Seira 具有成绩查询和分析功能。

但是，根据成绩及其回放在 `osu!` 服务器上的保存状态，可使用的功能可能有所不同。

> 本文中的“可用”主要指 Seira 是否能够从 `osu!` 服务器获取对应的成绩或回放，并不代表该成绩或回放是否仍然存在于玩家本地客户端中。

一般来说，一个成绩会处于以下几种状态之一：

| 情形 | 成绩已上传至 `osu!` 服务器 | 成绩回放在 `osu!` 服务器上可用 | 可在 Seira 查询 | 可在 Seira 分析、渲染回放等 |
| -- | ----------------- | ------------------- | ----------- | ----------------- |
| A  | ✓                 | ✓                   | ✓           | ✓                 |
| B  | ✓                 | ✗                   | ✓           | ✗（需手动上传回放）        |
| C  | ✗                 | ✗                   | ✗（需手动上传回放）  | ✗（需手动上传回放）        |

下面分别介绍这几种情况。

## A. 成绩、回放均可用

这是最常见的情况。

* 对于 `lazer`，在 `Ranked` 谱面上完成并成功上传的通过成绩通常处于此状态。
* 对于 `stable`，在 `Ranked` 谱面上完成并成功上传，且位于该谱面全球排行榜前 `1000` 名的成绩通常处于此状态。

这些成绩可以直接使用 Seira 的查询、分析、回放渲染等完整功能，无需进行额外操作。

这些成绩都有一个成绩 ID，可以直接使用该 ID 作为指令目标。

同时，如果某个成绩是你的最佳 100 个成绩之一，或最近 24 小时内的成绩之一，也可以使用[快捷查询](/guide/targets.html)指定。

## B. 成绩可用，回放不可用

这种情况下，成绩已经上传至 `osu!` 服务器，但服务器上没有可供 Seira 获取的回放。

* 对于 `lazer`，在非 `Ranked` 谱面上成功上传的成绩可能处于此状态。
* 对于 `stable`，不满足情形 A，且未开启 `Score V2` Mod 的成绩通常处于此状态。

这些成绩可以使用 Seira 查询基本信息，例如 `/s`，但无法直接使用涉及回放的成绩分析、回放渲染等功能。

如果你仍然保留着对应成绩的 `.osr` 回放文件，可以将其发送给 Seira。Seira 会保存该回放，并将其与对应的服务器成绩关联。

成功上传回放后，即可正常使用涉及回放的完整功能。

与情形 A 一样，可以使用成绩 ID 或[快捷查询](/guide/targets.html)指定指令目标。

## C. 成绩和回放均不可用

这种情况下，成绩没有上传至 `osu!` 服务器，因此 Seira 无法直接查询到它。

常见情况包括：

* 对于 `lazer`，在未联网、未登录，或本地谱面上完成的成绩一般属于此状态。
* 对于 `stable`，开启了 `Score V2`，或在未联网、未登录，或本地谱面上完成的成绩一般属于此状态。

这些成绩默认无法通过 Seira 查询。

如果你仍然保留着对应成绩的 `.osr` 回放文件，可以直接将其发送给 Seira。Seira 会根据回放计算成绩信息，并为该成绩分配一个以 `loc` 开头的本地成绩 ID。

上传后，可以使用这个本地成绩 ID 作为指令目标。
