# 开始使用机器人

## 添加 Seira


可以使用 QQ 号 `4015467215` 添加 Seira，也可以扫描二维码添加：

![4015467215](/md-asset/image/qr.png)

## 第一次使用

推荐先在私聊中完成账号绑定：

1. 发送 `/bind`。
2. 点击机器人返回的授权按钮，或复制授权链接到浏览器。
3. 在 20 分钟内完成 osu! OAuth 授权。
4. 返回 QQ，发送 `/bp` 验证绑定，机器人应返回你的最佳成绩。

::: warning 绑定安全
授权链接与当前 QQ 用户关联。虽然误绑定没有什么实际影响，
但仍然建议在私聊中完成绑定，不要把授权链接转发给他人。
若绑定错误，先发送 `/unbind`，再重新 `/bind`。
:::

## 发送指令

所有指令以斜杠 `/` 开头，指令名不区分大小写，参数之间使用空格分割。

```text
/rs
/rp2
/bp 5 peppy
/m bp2 HDDT
```

在群聊中通常需要先 @机器人：

```text
@Seira /lb
@Seira /m bp1
```

部分指令在群聊和单聊的行为不同：

| 功能         | 私聊         | 群聊                                   |
|--------------|--------------|----------------------------------------|
| `/f`         | 显示全部好友 | 仅显示当前群内出现过且已绑定的相关好友 |
| `/fall`      | 显示全部好友 | 显示全部好友                           |
| `/rsc`       | 不支持       | 支持                                   |
| 上传 `.osr`  | 支持         | 不支持                                 |
| 其余常规查询 | 支持         | 支持，通常需 @机器人                   |

机器人会在收到群消息时记录群成员与群聊的关联，
`/clearhistory` 可删除你自己的这些群聊记录。
这会使你不会出现在群内`/f`和`/lb`的结果里。

## 参数格式

文档中的记号含义如下：

- `<参数>`：必填。
- `[参数]`：可选。
- `A/B`：选择其中一种。
- `[参数...]`：可以按说明重复或提供列表。

玩家可以用 osu! UID、用户名或可解析的 QQ @用户指定。
谱面或成绩目标可以用纯数字 ID，也可以用 `rs5`、`bo3` 等快捷查询。
详见[目标与快捷查询](/guide/targets)。

## 示例指令

```text
/bind                 # 绑定 osu! 账号
/bp2                  # Top 2 成绩详情
/bp 8                 # 最好 8 条成绩汇总
/m rp1                # 最近通过成绩对应的谱面
/sa rp1               # 最近通过成绩的分析
/ma rp1               # 列出最近通过成绩的 Miss
/r rp1                # 自动渲染最近通过成绩的高光片段视频
```

注释仅用于解释，请不要把 `# 绑定 osu! 账号` 等注释一并发送给机器人。

## 可选：启用机器人额外权限 {#extra-permission}

::: warning 仅限群主
此部分的配置需要群主权限才能完成。
如果你的QQ显示的界面和下方截图不一样且没有相关配置，可以尝试更新QQ版本。
:::

受限于 QQ 机器人平台限制，默认情况下 Seira 在群聊中的部分功能可能无法使用。
如果想要启用这些功能，需要**群主**进行以下操作。

1. **在群中**打开群成员列表，点击 Seira 进入资料卡；
![进入资料卡](/md-asset/image/overview/use/permission-1.png)
2. 点击右上角的齿轮图标；
![齿轮图标](/md-asset/image/overview/use/permission-2.png)
3. 将 `机器人可获取的群聊消息范围` 切换为 `获取群内全部消息`，并打开 `机器人主动在群聊内发言`。
![权限设置](/md-asset/image/overview/use/permission-3.png)

::: tip 这些都有什么用？
这两个设定完全为可选项，不进行设定也可以使用 Seira 的绝大部分功能。
不过，在启用之后可以使用一些额外的功能。

**获取群内全部消息**: 
1. 可以免@调用指令
2. 在指定用户目标时可以直接使用 QQ @用户，以把被@用户绑定的账号作为目标

**机器人主动在群聊内发言**:
1. 使用成绩监视功能
2. 在猜 Rank 中启用阶段提示和自动结束

此列表可能会随功能增删以及 QQ 开放平台调整而进行更新。
:::
