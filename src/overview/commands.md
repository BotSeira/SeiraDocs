# 完整指令列表

## 账号、好友与群体功能

| 指令            | 用法                       | 作用                       | 备注                             |
|-----------------|----------------------------|----------------------------|----------------------------------|
| `/bind`         | `/bind`                    | 开始 osu! OAuth 绑定       | 授权链接 20 分钟内有效           |
| `/unbind`       | `/unbind`                  | 解除当前 QQ 用户的绑定     | 无                               |
| `/clearhistory` | `/clearhistory`            | 清除自己在群聊中的成员记录 | 会影响群筛选和群排行             |
| `/f`            | `/f`                       | 获取好友关系               | 需绑定；群聊中只显示群内相关玩家 |
| `/fall`         | `/fall`                    | 获取完整好友关系           | 需绑定                           |
| `/fclear`       | `/fclear`                  | 清除已同步的好友记录       | 需绑定                           |
| `/lb`           | `/lb [谱面目标] [UID列表]` | 表现分排行或谱面排行       | 无参数时使用当前群成员           |
| `/mp`           | `/mp`                      | 查看当前多人房间           | 需绑定且 OAuth Token 有效        |

详见[绑定、好友与排行](/commands/account-social)。

## 成绩与玩家

| 指令  | 用法                           | 作用                                               |
|-------|--------------------------------|----------------------------------------------------|
| `/bo` | `/bo [n] [UID/用户名/@用户]`   | 无参数查最佳成绩详情；有 n 时生成最好 n 条汇总     |
| `/bp` | 与 `/bo` 相同                  | `/bo` 的完整别名                                   |
| `/rs` | `/rs [n] [UID/用户名/@用户]`   | 无参数查最近一条；有 n 时生成最近 n 条，包含失败   |
| `/rp` | `/rp [n] [UID/用户名/@用户]`   | 无参数查最近一条通过；有 n 时生成最近 n 条通过成绩 |
| `/s`  | `/s [成绩ID/快捷查询]`         | 获取单条成绩图；可使用最近目标                     |
| `/sa` | `/sa [成绩ID/快捷查询]`        | 获取成绩分析图；可使用最近目标                     |
| `/ma` | `/ma [成绩ID/快捷查询] [n/#n]` | 列出 Miss 或可视化第 n 个 Miss                     |
| `/u`  | `/u <UID/用户名/@用户>`        | 获取玩家资料和最好成绩摘要                         |

详见[成绩查询与分析](/commands/scores)。

## 谱面与谱面集

| 指令     | 用法                    | 作用                                          |
|----------|-------------------------|-----------------------------------------------|
| `/m`     | `/m [谱面目标] [Mod]`   | 获取谱面信息；可使用最近目标                  |
| `/ap`    | `/ap [谱面目标]`        | 获取谱面音频预览；可使用最近目标              |
| `/bgp`   | `/bgp [谱面目标]`       | 获取谱面背景预览；可使用最近目标              |
| `/ms`    | `/ms [谱面集目标]`      | 获取谱面集信息；可使用最近目标                |
| `/dl`    | `/dl [谱面集目标]`      | 获取谱面集镜像下载入口；可使用最近目标或 `mp` |
| `/sms`   | `/sms [#页数] <关键字>` | 搜索谱面集                                    |
| `/daily` | `/daily`                | 获取 osu! 每日挑战信息                        |
| `/luck`  | `/luck`                 | 获取当天固定的“今日人品”和推荐谱面集          |

详见[谱面与谱面集](/commands/beatmaps)。

## 回放与视频

| 指令     | 用法                                | 作用                             | 备注                       |
|----------|-------------------------------------|----------------------------------|----------------------------|
| `/r`     | `/r [成绩目标] [[开始]-[结束]]`     | 渲染高光、片段或完整回放         | 省略目标时使用最近目标     |
| `/rsc`   | `/rsc [谱面目标] [+ID列表/=ID列表]` | 生成多人同屏回放                 | 仅群聊                     |
| `/rstat` | `/rstat [任务ID]`                   | 查询渲染状态或重新取得已完成视频 | 省略 ID 时查自己的最近任务 |

详见[回放与视频](/commands/replays)。

| `/help`    | `/help`    | 显示机器人内置简要帮助                   |
