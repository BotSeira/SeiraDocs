# 群挑战

`/gch` 在当前群聊中组织 osu!standard 挑战。每场使用一个谱面集，可限制为其中一个难度，也可让玩家自由选择难度。

## 配置后开始

```text
/gch configure
```

机器人显示当前配置和按钮。选择指定谱面、指定谱面集或随机谱面，修改难度、Mod、时长等设置后：

```text
/gch start
```

地图、时长和星数范围按钮会填入指令，补充参数后发送即可。其他按钮可直接切换设置。
每次修改都会返回完整配置与新按钮，旧按钮不能覆盖更新后的设置。
配置由创建者管理，机器人管理员也可以修改或开始。`/gch configure reset` 重置配置。
开始后，本场规则固定；修改配置只影响下一场。

## 文字设置

也能使用以下指令：

| 设置     | 示例                      | 含义                                                       |
|----------|---------------------------|------------------------------------------------------------|
| 谱面集   | `/gch set set 12345`      | 指定一个谱面集                                             |
| 谱面     | `/gch set map 67890`      | 指定具体谱面，并切换为固定难度                             |
| 随机     | `/gch set random`         | 从 Seira 内置谱面集池抽取，选中符合星数范围的难度          |
| 重抽     | `/gch set reroll`         | 重新抽取并显示候选，开始前可核对                           |
| 难度     | `/gch set difficulty any` | 允许该谱面集内不同难度；`fixed` 只允许配置中显示的固定难度 |
| 必选 Mod | `/gch set required HDHR`  | 必须同时使用 HD 和 HR；其他未禁用 Mod 仍可使用             |
| 禁用 Mod | `/gch set banned DT,FL`   | 不允许 DT/NC 与 FL                                         |
| 清空 Mod | `/gch set required none`  | 清空必选限制；禁用限制用 `banned none` 清空                |
| NM       | `/gch set required NM`    | 不允许其他 Mod，CL 除外；仍可显式禁用 CL                   |
| 星数     | `/gch set stars 3-7`      | 限制谱面的基础星数，包含边界；范围为 0–15★                |
| 时长     | `/gch set hours 24`       | 1–168 小时，默认 24 小时                                   |
| 水平调整 | `/gch set skill on`       | 开启水平奖励/惩罚，默认开启；`off` 直接比较标准化分数      |

NC 在必选和禁用规则中等同 DT，PF 等同 SD。
不能同时必选与禁用同一 Mod，不能必选 HR+EZ、DT+HT、NF+SD 等冲突组合。
支持 NM/NF/EZ/HD/HR/SD/DT/NC/HT/FL/SO/PF/CL/MR 的默认设置；辅助、自动、自定义速率等 Mod 不计入。

随机结果来自内置谱面集池，不代表 osu! 全部谱面。改变星数范围后可重新抽取；抽取完成后会显示结果，开始指令使用已显示的结果。
开始前至少要有一张符合范围的 ranked/approved osu!standard 谱面。

也可快速使用默认设置：`/gch start <谱面集ID> [小时数]`。如果已有配置，只有其创建者或机器人管理员能用这个快捷方式开始。

## 报名与成绩

```text
/gch join
/gch status
/gch lb
/gch lb 2
/gch submit 123456789
/gch end
/gch rules
```

- 只能在群聊中使用，每群同时一场，最多 100 人。
- 群成员用自己绑定的账号报名，每个 osu! 账号只允许一位群成员报名，同一群成员不能在本场更换账号。
- 只接受报名后、截止前完成的在线通过成绩；其他谱面、其他账号、失败成绩和不符合 Mod 规则的成绩无效。
- 每位玩家可以多次游玩，任意合格难度中最高的挑战分进入排行。
- 自动轮询每位报名玩家最近 20 条通过成绩。
- 如果两次轮询之间完成太多成绩，或 API 延迟导致成绩漏收，可在结算完成前用 `submit <在线成绩ID>` 补交。已结束的挑战不能补交。
- 发起者或机器人管理员可提前结束；机器人最后收集一次截止前的成绩，再公布结果。未获取成功时继续重试。
- 需要主动消息权限才能自动发送最终结果；发送失败会重试，也可通过 `/challenge lb` 查看已保存的排行。

## 水平计分

报名时，从前 50 条 BP 中选取最多 20 张其他谱面的合格成绩，使用其 **Mod 后星数中位数** 估计水平。
相同谱面只算一次，挑战谱面集不参与估计。至少需要 5 张有效样本；开启水平调整时，样本不足的玩家无法报名。
估计在报名后固定，重复报名不会重新计算。关闭水平调整时不要求 BP 样本。

```text
差值 = 成绩的 Mod 后星数 − 报名时水平
差值 ≥ 0：倍率 = min(1.10, 1 + 0.05 × 差值)
差值 < 0：倍率 = max(0.50, 1 + 0.20 × 差值)
挑战分 = 四舍五入(标准化分数 × 倍率)
```

例如，水平为 5★：游玩 6★ 获得 5% 奖励，游玩 4★ 扣除 20%；最高奖励 10%，最大惩罚 50%。
难图仍需取得较好的原始成绩才能获胜。星数中位数是水平估计，并非针对每种技能的精确测量。
同分按准确率、较早完成时间排序，最终按成绩 ID 稳定排序。
