# 新增 PP 估算

## `/addpp`：新增成绩后的 PP 与排名 {#addpp}

需要先 `/bind`，使用自己的绑定账号；群聊和私聊均可使用。目前支持 **osu!standard**。

### 直接指定成绩 PP

```text
/addpp 123
/addpp 200*4
```

第一条表示新增一条 123pp 成绩；第二条表示新增四条 200pp 成绩，按不同谱面的新成绩处理。
支持小数和可选 `pp` 后缀，例如 `/addpp 200.5pp*4`。
单条 PP 必须大于 0 且不超过 100000，条数为 1–100，省略条数时为 1。

机器人会将这些成绩插入 BP、重新排序并计算加权变化，返回：

- 当前总 PP、预计总 PP，以及增加的 PP。
- 当前全球排名、预计全球排名，以及预计上升的名次。
- 新成绩在 BP 中的位置。

### 指定谱面和成绩条件

```text
/addpp m1234567 HDDT 97.41% 13miss 18ok 1200x
/addpp m1234567 1200x 18ok 13miss 97.41% HDDT
/addpp m1234567 HD 98% FC
/addpp m1234567 18ok 2meh
```

`m` 后为**谱面 ID**，条件顺序不限；仅接受 ranked/approved 的 osu!standard 原生谱面。
机器人会先计算该成绩的 PP，再估算 BP 更新后的总 PP 和排名。
同图在获取的 BP 中已有成绩时，只保留更高 PP 的一条，较差成绩不会降低原有 PP。

| 条件       | 示例                  | 含义                                                 |
|------------|-----------------------|------------------------------------------------------|
| Mod        | `HDDT`、`+HDHR`、`NM` | 省略为 NM；多个 Mod 合并为一个条件                   |
| ACC        | `97.41%`              | 0%–100%，按输入的小数精度核对可实现的整数判定        |
| 300        | `500great`            | 指定 300 数量                                        |
| 100        | `18ok`                | 指定 100 数量                                        |
| 50         | `2meh`                | 指定 50 数量                                         |
| Miss       | `13miss`              | 省略为 0                                             |
| 最大 Combo | `1200x`、`1200combo`  | 有 Miss 时必须提供；没有 Miss 且省略时按 FC          |
| FC         | `FC`                  | 要求零 Miss、满 Combo；可以与非 100% 的 ACC 一起使用 |

至少给出 ACC 或一项判定数量。只有 Mod、Combo 或 FC 时会提示条件不足。
只有判定数量时，未指定的 100/50 按 0、剩余物件按 300 处理。
给出 ACC 时，在已指定的判定约束下补全缺失判定；同样接近 ACC 的方案优先选择更少的 50。
回复会展示实际采用的 ACC、Combo 和 300/100/50/Miss，方便核对。

以下情况会明确提示：

- 有 Miss 却没有最大 Combo，例如原始 `/addpp m1234567 HDDT 97.41% 13miss 18ok` 需要补充 `1200x` 等实际 Combo。
- ACC、判定或 Mod 等条件重复；Mod 不支持或矛盾，例如 HREZ、DTHT、NFSD。
- FC 与 Miss/非满 Combo、PF 与非 100% 判定冲突。
- 判定数量超过物件总数，ACC 无法由指定判定得到，或 Combo 超出上限。

支持默认设置的 NF/EZ/HD/HR/SD/DT/NC/HT/FL/SO/PF/CL/MR；不接受辅助、自动或自定义速率 Mod。

### 估算范围

PP 根据当前最多 **200 条 BP** 重排，以 `0.95^(位置-1)` 加权。保留账号当前总 PP 中未获取的剩余部分；
前 200 之外成绩的重排、新增 bonus PP 和同图在样本外的旧成绩不在本次估算中，因此结果可能与实际略有偏差。
成绩未进入前 200 时只报告该窗口内的零收益。
