# 新增 PP 估算

## `/addpp`：新增成绩后的 PP 与排名 {#addpp}

默认使用自己的绑定账号，需要先 `/bind`；群聊和私聊均可使用。目前支持 **osu!standard**。

语法为 `/addpp [user] X*Y` 或 `/addpp [user] m谱面ID [条件...]`。user 支持 UID、用户名或 @用户，放在成绩参数前。含空格的用户名请用双引号包裹。指定 UID 或用户名时，自己无需绑定；@提及用户时，对方需要已绑定。单独一个数字仍表示给自己新增的 PP。

例如：`/addpp peppy 200*4`、`/addpp "Player Name" 200`、`/addpp @用户 m1234567 HD 98% FC`。

### 直接指定成绩 PP

```text
/addpp 123
/addpp 200*4
```

第一条表示新增一条 123pp 成绩；第二条表示新增四条 200pp 成绩，按不同谱面的新成绩处理。
支持小数和可选 `pp` 后缀，例如 `/addpp 200.5pp*4`。
单条 PP 必须大于 0 且不超过 100000，条数为 1–100，省略条数时为 1。

机器人会将这些成绩插入 BP、重新排序并计算加权变化，返回：

- 当前总 PP、预计总 PP，以及增加的 PP。
- 当前全球排名、预计全球排名，以及预计上升的名次。
- 新成绩在 BP 中的位置。

### 指定谱面和成绩条件

```text
/addpp m1234567 HDDT 97.41% 13miss 18ok 1200x
/addpp m1234567 1200x 18ok 13miss 97.41% HDDT
/addpp m1234567 HD 98% FC
/addpp m1234567 18ok 2meh
```

也可以将 `m谱面ID` 替换成与 `/s` 相同的快捷查询：

```text
/addpp rp HD 98%
/addpp @用户 bp5 97.41% 13miss
/addpp "Player Name" rs2 18ok
```

`rs[N]` 为最近成绩（含失败），`rp[N]` 为最近通过成绩，`bp[N]` 为最好成绩；N 省略时为 1，范围 1–200，大小写不限。
前置玩家支持 UID、用户名或 @用户；省略时使用自己的绑定账号。该玩家同时是成绩查询与 PP 估算的目标。
快捷查询仅获取谱面，不继承原成绩的 Mod、ACC 或判定；后面的条件仍按本指令规则传给 rosu-pp。

`m` 后为**谱面 ID**，条件顺序不限；仅接受 ranked/approved 的 osu!standard 原生谱面。
机器人会先计算该成绩的 PP，再估算 BP 更新后的总 PP 和排名。
同图在获取的 BP 中已有成绩时，只保留更高 PP 的一条，较差成绩不会降低原有 PP。

| 条件       | 示例                  | 含义                                                 |
|------------|-----------------------|------------------------------------------------------|
| Mod        | `HDDT`、`+HDHR`、`NM` | 省略为 NM；多个 Mod 合并为一个条件                   |
| ACC        | `97.41%`              | 0%–100%，直接传给 rosu-pp，不要求精确匹配整数判定    |
| 300        | `500great`            | 指定 300 数量                                        |
| 100        | `18ok`                | 指定 100 数量                                        |
| 50         | `2meh`                | 指定 50 数量                                         |
| Miss       | `13miss`              | 指定 Miss 数量                                       |
| 最大 Combo | `1200x`、`1200combo`  | 指定最大 Combo 数量                                  |
| FC         | `FC`                  | 要求零 Miss、满 Combo；可以与非 100% 的 ACC 一起使用 |

所有成绩条件均可省略，也可以只给 Mod、Combo、Miss 或部分判定，例如 `/addpp m1234567 HD`、`/addpp m1234567 13miss`。
如果条件不全，会尝试推算未给出的条件。无法识别、不支持、重复、明显冲突会报错。

支持默认设置的 NF/EZ/HD/HR/SD/DT/NC/HT/FL/SO/PF/CL/MR；不接受辅助、自动或自定义速率 Mod。

### 估算范围

PP 根据当前最多 **200 条 BP** 重排，以 `0.95^(位置-1)` 加权。保留账号当前总 PP 中未获取的剩余部分；
前 200 之外成绩的重排、新增 bonus PP 和同图在样本外的旧成绩不在本次估算中，因此结果可能与实际略有偏差。
