# 谱面与谱面集

## `/m`：谱面信息

```text
/m [谱面目标] [Mod]
```

```text
/m 123456
/m m123456 HD
/m rs2
/m peppy bo1 DT
/m
```

目标可以是谱面 ID、`mID`、成绩快捷查询、`谱面集ID#难度序号` 或 `mp`。
Mod参数形如 `HD`、`HDDT`。无效的Mod会被忽略。

## `/ms`：谱面集信息

```text
/ms [谱面集ID或快捷查询]
```

```text
/ms 12345
/ms rs1
/ms 12345#2
/ms
```

纯数字会被当作谱面集 ID；快捷查询会先定位成绩或谱面，再查找其谱面集。省略目标时使用最近目标。

## `/dl`：镜像下载入口

```text
/dl [谱面集ID或快捷查询]
```

返回目标谱面集及可选镜像下载按钮：

```text
/dl 12345
/dl bo1
/dl mp
/dl
```

`mp` 表示当前绑定玩家所在多人房间使用的谱面。此类解析需要有效绑定。

## `/sms`：搜索谱面集

```text
/sms [#页数] <搜索关键字>
```

```text
/sms xi
/sms #2 xi
/sms #3 artist title
```

页数必须是正整数，并且 `#页数` 后要有空格和非空关键字；省略时为第 1 页。

## `/luck`：今日人品

```text
/luck
```

随机抽签生成今日运势。一天内同一用户的结果保持一致。

## `/ap`：音频预览

```text
/ap [谱面目标]
```

解析目标对应的谱面集，并发送对应的预览音频。

```text
/ap 123456
/ap rs1
```

## `/bgp`：背景预览

```text
/bgp [谱面目标]
```

生成或取得目标谱面的背景预览。

## `/daily`：每日挑战

```text
/daily
```

获取 osu! 每日挑战信息并返回。
