# 成绩查询与分析

## `/bp`：最好成绩 {#bp}

> `/bo` 是 `/bp` 的完整别名。

### 单条详情

```text
/bp
```

使用自己的绑定 UID 查询最好成绩第 1 条，并返回单条成绩详情。未绑定时无法使用。

### 多条汇总

```text
/bp <数量> [UID/用户名/@用户] [过滤条件 ...]
```

```text
/bp 5
/bp 10 peppy
/bp 3 124493
```

数量必须是 1–200 的整数。只提供一个参数时，该参数会被当作数量；若想查询指定玩家，即使只要一条也要写 `/bo 1 peppy`。

### 过滤成绩

`/bo`、`/bp`、`/rs`（以及 `/rp`）可在原参数后追加一个或多个过滤条件，多个条件同时满足才会展示：

```text
/bp 10 acc>=98 combo>=1000
/bp 8 peppy mod~HD mod!~DT pp>=300
/rs 12 time<2:30 rank!=F
```

`<数量>` 表示先获取多少条原始成绩，再在这些成绩上应用过滤；因此过滤后的实际展示数量可能少于 `<数量>`。数量超过 100 时，系统会继续获取第 101–200 条后再统一过滤。支持的字段和写法如下：

| 字段                      | 含义                 | 支持的运算符                                         | 示例                                  |
|---------------------------|----------------------|------------------------------------------------------|---------------------------------------|
| `acc` / `accuracy`        | 准确率，数值按百分比 | `>` `>=` `<` `<=` `=` `!=`                           | `acc>=98.5`                           |
| `combo`                   | 最大连击             | 数值运算符                                           | `combo>=1000`                         |
| `pp`                      | PP                   | 数值运算符                                           | `pp>300`                              |
| `time` / `length` / `len` | 原谱面总时长         | 数值运算符                                           | `time<150`、`time<2:30`、`time<2m30s` |
| `star` / `sr`             | 星数                 | 数值运算符                                           | `star>=6.5`                           |
| `bpm`                     | BPM                  | 数值运算符                                           | `bpm>180`                             |
| `miss`                    | Miss 数              | 数值运算符                                           | `miss=0`                              |
| `score`                   | 总分                 | 数值运算符                                           | `score>=1000000`                      |
| `rank`                    | 成绩评级             | `=` `!=`                                             | `rank!=F`                             |
| `mod` / `mods`            | Mod 集合             | `~` 包含、`!~` 不包含、`=` 完全等于、`!=` 不完全等于 | `mod~HD`、`mod=HDDT`、`mod=NM`        |

运算符也可写成中文，例如 `combo大于1000`、`mod包含HD`、`mod不等于NM`。条件内部不能留空格。

## `/rs`：最近成绩 {#rs}

```text
/rs
/rs <数量> [UID/用户名/@用户] [过滤条件 ...]
```

- 无参数：返回本人最近成绩第 1 条详情。
- 有数量：生成最近 n 条成绩汇总，包含失败成绩。

```text
/rs
/rs 5
/rs 5 peppy
```

## `/rp`：最近通过成绩 {#rp}

用法与 `/rs` 相同，但过滤失败成绩：

```text
/rp
/rp 5
/rp 5 124493
```

无参数时等价于取本人 `rp1` 的单条成绩详情。

## `/s`：单条成绩 {#s}

```text
/s [成绩ID或快捷查询]
```

```text
/s 1234567890
/s rs5
/s peppy bo3
/s
```

显式目标会成为该用户的最近目标。省略目标时沿用最近一次目标；若没有最近目标则显示用法。

也可以直接发送 `/rs5`、`/rp2`、`/bo3`，解析器会把这种完整快捷指令路由到 `/s`。

## `/sa`：成绩分析 {#sa}

```text
/sa [成绩ID或快捷查询]
```

生成指定成绩的分析图。目标解析、最近目标和快捷查询规则与 `/s` 相同。

```text
/sa 1234567890
/sa rs1
```

## `/ma`：Miss 分析 {#ma}

`/ma` 可以先列出 Miss，也可以可视化指定的某一次 Miss。

### 列出 Miss

```text
/ma [成绩ID或快捷查询]
```

```text
/ma rs1
/ma
```

不提供 Miss 序号时返回该成绩的 Miss 列表。省略目标时必须已有最近目标。

### 可视化一个 Miss

```text
/ma <成绩ID或快捷查询> <序号>
/ma #<序号>
```

```text
/ma rs1 2
/ma 1234567890 1
/ma #3
```

当显式提供成绩目标时，序号可写 `2` 或 `#2`；当省略目标并沿用最近目标时，
必须写 `#2`，否则数字会被误认为成绩 ID。序号必须为正整数。

## `/u`：玩家资料 {#u}

```text
/u <UID/用户名/@用户>
```

```text
/u peppy
/u 2
/u @某人
```

当前实现内部把它转换为 `/bo 8 <玩家>`，因此返回玩家信息和 8 条最好成绩摘要，而不是一个完全独立的资料接口。目标必须显式提供，不能省略为本人。

## `/wx`：成绩监视 {#wx}

```text
/wx start <UID列表> <谱面ID列表>
/wx stop
```

开始监视指定玩家在指定谱面取得的成绩，成功获取后会发送成绩ID。
监视任务会持续存在并运行，直到执行了 `/wx stop` 。
