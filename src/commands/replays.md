# 回放与视频

## `/snap`：回放快照 {#snap}

`/snapshot` 是完整别名。生成一张 1920×1080 的 osu!standard 游玩快照，使用 WhiteCat 2.1 皮肤。

```text
/snap [成绩ID或快捷查询] <时间/obj物件序号/#Miss序号> [±偏移ms]
```

```text
/snap rp1 01:23.456
/snap loc123456789 83.456s
/snap obj123
/snap #3 -50ms
/snapshot peppy bp1 83456ms
```

时间可写 `mm:ss.fff`、`83.456s`、`83456ms`，小数最多 3 位。时间按原谱面歌曲时钟解释，DT/NC/HT 下仍保持这一规则。
物件从 1 开始编号，`obj123` 或 `object123` 定位第 123 个物件的开始时间。
`#3` 或 `miss3` 定位 `/ma` 列表中的第 3 个 Miss 判定发生后，可用偏移查看判定前后；偏移默认 0，上限 ±60000ms。
目标时间必须在歌曲范围内，完整回放结束后保留 1 秒播放时间用于查看最后的判定；未完成的回放只能选择已经记录的时间。

目标解析规则与 `/ma` 相同，支持在线成绩、上传后的 `loc` 本地成绩和玩家快捷查询。
省略成绩目标时沿用最近目标；没有最近目标时显示用法。纯数字保留为成绩 ID，因此时间需要单位或冒号，物件和 Miss 需要前缀。

画面包含物件、缩圈、判定、滑条轨道与折返、滑条球与跟随状态、鼠标和轨迹、判定条、按键指示与累计次数、
歌曲进度、当前连击、准确率和实时 PP。物件位置与大小使用 CS、堆叠、HR 数据；显隐时间使用 AR、HD 与实际击打时间。
滑条位置按真实曲线长度、节拍、SV 和折返计算；计数器只处理目标时间之前的判定。

回放没有记录客户端的分辨率、光标大小等个人设置，快照采用固定布局和 82% 背景变暗。
精度受回放帧采样与现有判定分析影响，PP 使用后端的 rosu 算法计算；Storyboard、视频和失败时的屏幕旋转不绘制。
目前不支持 FL、Random、Mirror、DA 等改变画面或物件规则的新 Mod，以及自定义变速。

## `/r`：单人回放 {#r}

```text
/r [成绩ID或快捷查询] [[开始]-[结束]]
```

### 自动高光

```text
/r rs1
/r 1234567890
```

省略时间范围时，会自动识别20秒高光区间并在开始前和结束后各扩展约 5 秒。

::: tip 高光识别算法
目前 Seira 会计算成绩的每个20秒区间，取其中 `区间最大表现分 * (区间准确率 ^ 3)` 作为区间评分，
选出最高的区间作为高光。
:::

### 指定片段

时间可以写纯秒数或 `分钟:秒`，两端都可省略：

```text
/r rs1 60-90
/r rs1 01:00-01:30
/r rs1 -01:30
/r rs1 02:00-
```

`-01:30` 表示从开头到 1 分 30 秒；`02:00-` 表示从 2 分钟到结尾。

### 完整回放

```text
/r rs1 -
```

单独的 `-` 表示完整回放。完整或很长的回放需要更多渲染时间，也更容易遇到消息回复超时。

## `/rsc`：多人同屏回放 {#rsc}

`/rsc` 仅支持群聊。当前实际可用格式为：

```text
/rsc [谱面ID或快捷查询] [+ID列表]
/rsc <谱面ID或快捷查询> =ID列表
```

### 使用群成员

```text
/rsc 123456
/rsc rs1
```

默认收集本群已记录且已绑定的玩家 UID，并为目标谱面创建同屏回放。

### 群成员加额外玩家

```text
/rsc 123456 +124493,2
```

`+` 会把逗号分隔的标识追加到群成员中。

### 只使用显式玩家

```text
/rsc 123456 =124493,2
```

`=` 不加入本群成员，只使用显式列表。当前解析器在目标省略时不会把 `=...` 识别为可选参数，因此此模式必须显式提供谱面目标。

标识可以使用 `数字` (解析为用户UID), `u数字` (解析为用户UID)或 `s数字` (解析为成绩ID)形式。

## `/rstat`：渲染状态 {#rstat}

```text
/rstat
/rstat <任务ID>
```

- 无参数：查询当前用户最近提交的渲染任务。
- 有任务 ID：查询指定任务。
- 如果视频已经完成并暂存在内存中，会直接重新发送视频；发送成功后移除该缓存。

最近任务 ID 和已完成视频缓存都在进程内存中，机器人重启后可能无法通过无参数形式找回。

查询排队中、渲染中或上传中的任务时，消息按钮中会提供“取消渲染”。

## `/rcancel`：取消渲染 {#rcancel}

```text
/rcancel <任务ID>
```

取消仍在排队、渲染或上传的回放任务。排队任务会直接从队列移除；正在渲染的任务会立即终止渲染进程。已经完成、失败或超时的任务不会被改写为取消状态。

## 私聊上传 `.osr` {#uploadReplay}

不需要指令，直接在私聊中发送回放文件即可。当前限制：

- 后缀必须是 `.osr`。
- 文件不得超过 512 KiB。
- 只处理私聊文件附件。

上传成功后，可在后续成绩分析或渲染过程中使用这份回放。若 osu! 服务器没有保存某条成绩的回放，这是补充回放的主要方式。
