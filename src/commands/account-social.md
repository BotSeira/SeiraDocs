# 绑定、好友与排行

## `/bind`：绑定 osu! 账号

```text
/bind
```

机器人会生成一条 osu! OAuth 授权链接，有效期为 20 分钟。
成功登录并授权后即可绑定成功。

- 已绑定时不会覆盖旧绑定，请先 `/unbind`。
- 建议私聊使用，避免授权链接被他人误操作。

## `/unbind`：解除绑定

```text
/unbind
```

删除当前 QQ 用户的 osu! 绑定。未绑定时会提示无需解绑。
解绑后，所有依赖本人绑定或 OAuth Token 的功能都需要重新 `/bind`。

## `/clearhistory`：清除群聊记录

```text
/clearhistory
```

删除当前 QQ 用户在数据库中的群成员关联，并返回删除数量。
它不会删除 osu! 绑定、好友记录或成绩数据。

适合在不希望继续出现在群排行或群好友筛选中时使用。
之后只要机器人再次收到你在群里的消息，该群记录会重新建立。

## `/f` 与 `/fall`：好友列表

```text
/f
/fall
```

两者都会读取关注列表，并把好友关系同步到本地数据库：

- `/f` 在私聊中显示完整结果；在群聊中仅显示当前群已记录成员中的相关玩家。
- `/fall` 无论私聊还是群聊都显示完整结果。

结果区分互相关注、仅自己关注和仅对方关注，并优先显示在线用户。需要绑定账号。

::: tip Token 失效
有时由于技术问题可能会导致绑定失效。
若收到相关提示， 执行 `/unbind` 解绑后再使用 `/bind` 重复绑定流程即可。
:::

## `/fclear`：清除好友记录

```text
/fclear
```

清除当前绑定账号对应的本地好友关系。
这会使你不出现在别人的 `/f` 或 `/fall` 的 `仅粉丝` 部分里。
使用 `/f` 或 `/fall` 后会重新同步好友关系。

## `/lb`：排行榜

`/lb` 有三种工作方式。

### 表现分排行

```text
/lb
```

对本群已记录且已绑定的玩家生成表现分排行。

### 指定谱面排行

```text
/lb <谱面ID或快捷查询>
```

使用群成员或私聊中的本人作为玩家集合，生成指定谱面的成绩排行。

```text
/lb 123456
/lb rs1
/lb peppy bo1
```

### 自定义玩家集合

```text
/lb <谱面ID或快捷查询> <UID1,UID2,...>
```

UID 必须是逗号分隔的正整数，列表内部不要插入空格：

```text
/lb 123456 124493,7562902,2
```

如果提供了列表，就不会自动使用群成员。

## `/mp`：多人房间

```text
/mp
```

查询当前绑定玩家所在的 osu! 多人房间(仅 lazer 可用)，并返回房间信息和相关入口。需要有效绑定。

多人房间目标 `mp` 也能被部分谱面指令使用，用来指向当前所在房间的当前铺面，例如 `/m mp` 或 `/dl mp`。
