# 交互与娱乐

## `/rg`：猜 Rank 游戏 {#rg}

`/rg` 仅支持群聊，每个群同时只能进行一轮游戏。

### 子指令

#### `/rg start`, `/rg group`：开始猜 Rank 游戏

- `/rg start`：随机选择一条成绩，匿名渲染其高光。视频发送后即可开始猜测。
- `/rg group`：随机选择一条 **群友** 的成绩进行游戏。

开始游戏后，Seira会随机选择一条成绩，渲染其回放片段，以供猜测。

如果开启了主动消息权限，会使用阶段提示，即每隔一段时间（第一个提示为 1 分钟，之后为 30 秒）给出一个提示。
每场游戏给出的提示类型，顺序，明显程度均为随机决定，且游戏进度越后，给出较明显提示的概率就越高。
当所有提示均被揭示后，会等待 30 秒并自动结束与结算。

如果无主动消息权限，将会一次性给出所有提示，且需要使用 `/rg end` 主动结束。

如果给出提示时有人精确命中了 Rank，将会把有人精确命中作为提示给出，然后在 30 秒后结束游戏与结算。

结算时，会根据所有人的猜测，及其分数倍率计算得分，并给出得分排名。
除此之外，还会揭示本成绩的玩家名、玩家 ID 和成绩 ID 供查询。

如果结算时参与人数不少于 3 人，且启用了阶段提示，
则会将每个人的猜测战绩记录下来，供查询个人统计信息以及群友排行榜。

#### `/rg #Rank`：猜测排名

```text
/rg #123456
/rg 120k
/rg @someone
```

对当前的猜 Rank 游戏进行猜测。可以使用 `#` 前缀或直接输入数字，可以输入纯数字以及 `数字+k/w`。

也可以通过输入 `/rg @username` 来使用输入的用户名所对应的玩家的排名进行猜测。

如果你认为目标玩家是某位群友，或认为其水平与某位群友接近，也可以使用 QQ @ `/rg @群成员` 来使用被 @ 的用户
所绑定的玩家的排名进行猜测（**需要群主开启获取所有消息权限**）。

猜测后会显示猜测结果，其中包含了当前的分数倍率。
你可以多次修改你的猜测，但每次修改间隔需要大于20秒，修改后分数倍率会重新计算。

#### `/rg end`：主动结束游戏

主动结束当前的猜 Rank 游戏。在游戏开始的三分钟内，只有发起者以及Bot管理员可以主动结束，之后群内成员均可结束。

#### `/rg wish`：许愿

你可以使用此指令进行许愿。
许愿后，你被 `/rg group` 选作目标的权重会有所提升。

#### `/rg stats`：个人统计数据

- `/rg stats`：获取 **本群** 中的个人统计数据。
- `/rg stats all`：获取 **所有群** 中的个人统计数据。

根据你在本群/所有群中的猜 Rank 记录，获取你的猜 Rank 统计数据。
数据包含 Rating，总参与数，获胜数，胜率，前20%数等。

#### `/rg lb`：排行榜

- `/rg lb`：获取你在本群中的 Rating 排名，以及排行榜上你附近的人。
- `/rg lb all`：获取本群的完整 Rating 排名。

#### `/rg weight`：本群权重数据

获取你在本群的相关权重信息。包含你目前的用户权重，被抽选的概率，
以及你最高权重的最多 12 条成绩及其对应权重。

成绩权重进行过归一化，权重最大的成绩的权重取 `1.0`。

### 部分机制

#### 成绩选择

在开始猜Rank时，会先随机选定用户，再随机选定成绩。

如果使用的是全随机，则会获取最近提交到 osu! 服务器上的 100 个成绩并取其玩家，并以相同权重随机取一名玩家。

如果使用的是群组猜 Rank，则会将当前群组的用户作为候选者进行加权随机选择。
许愿后的玩家权重为 `2.5`，最近 `5` 次被抽选过的玩家权重为 `0.25`，其余玩家权重为 `1.0`。

在抽选完成后，会获取玩家的 `BP40`，过滤其中回放不可用的成绩，并根据 `谱面类型` 和 `BP位置` 计算权重。

如果玩家的 `BP41-80` 中有权重非常突出的成绩，也会被纳入考虑范围。

如果被选中的用户的所有成绩均不可用，将会再抽选一名玩家。

部分影响权重的因素如下：

- 偏向 `Tech / Reading / Flow` 等类型的图的成绩会获得较高的权重。
- `CS` 非常高，`AR` 非常高/非常低的成绩会获得额外的权重提升。
- 使用 `EZ` `HR` 的成绩会获得额外的权重提升，`HDDT` 的成绩会有略微下降。
- `BP位置` 靠前的成绩也会有略微的权重提升。
- 被抽选过的谱面的权重会下降，抽选次数越多下降越多。

#### 排行榜

排行榜使用对数误差计分：

```text
error = |log10(猜测 Rank) - log10(实际 Rank)|
得分 = max(0, 1000 × (1 - error))
```

因此，相同比例的偏差会得到相近评价；完全猜中可得 1000 分。

#### 分数倍率

为了平衡不同猜测时机的分数，每个猜测结果在排行榜排名时都会进行相应的倍率调整。

目前有以下几个影响倍率的情况：

- 提示被揭示。会根据猜测时已经揭示的提示来调整倍率。提示越明显，减少越多。
- 猜测顺序。首猜会有 `+5%` 的加成，之后每次猜测都会有所减少，最多 `-10%`。
- 抄袭惩罚。如果你的猜测和现有的其他玩家的猜测过于接近，将会受到 `-5%` 的抄袭惩罚。若游戏参与人数较多，会降低为 `-2.5%`。

在重新做出猜测，倍率会重新计算。

## `/watch`：成绩监视 {#watch}

`/watch` 可以在群聊中监视指定玩家的成绩更新。监视的成绩会在群里自动发送。

### `/watch add`：添加监视

```text
/watch add <UID/用户名/@用户> [时间]
```

添加监视。参数中 `时间` 是可选的，表示监视的时长，单位为分钟，可用范围为 1-120 分钟。若省略则默认 10 分钟。

### `/watch del`：移除监视

```text
/watch del [UID/用户名/@用户]
```

删除监视。若省略目标，则删除当前群中所有监视。

### `/watch list`：列出监视

```text
/watch list
```

列出当前群中生效的所有监视任务。

## `/mpwatch`：多人房间监视 {#mpwatch}

`/mpwatch` 仅支持群聊。它可以监视 osu!stable 或 osu!lazer 多人房间，在每张谱面完成后向群内推送一张 oStella 结果图；房间结束后会发送提示并自动停止。

```text
/mpwatch
/mpwatch [start] <房间ID> [stable|lazer]
/mpwatch [start] <房间链接>
/mpwatch status
/mpwatch stop
/mpwatch stop all
```

- 无参：相当于 `/mpwatch start`，会尝试获取当前用户绑定的玩家所在的 lazer 房间。
- `start`：可省略，`/mpwatch <参数>` 与 `/mpwatch start <参数>` 等价。
启动前已经完成的谱面不会补发；每名用户在同一群中可以启动一个监视，再次启动只会替换自己的任务。
同一房间在同一群中只能由一名用户监视，但不同群互不影响。
- 房间 ID：可在 ID 后指定 `stable` 或 `lazer`；省略版本时默认为 `lazer`。
- 房间链接：lazer 的 `/multiplayer/rooms/<ID>` 和 stable 的 `/community/matches/<ID>`（以及旧式 `/mp/<ID>`）会自动识别 ID 与版本。
- `status`：查看自己在当前群启动的房间监视。
- `stop`：停止自己在当前群启动的房间监视；`stop all` 会停止当前群的全部房间监视。

结果图包含本轮谱面信息、加谱玩家，以及每位玩家选择的难度、MOD、ACC、combo、分数、PP、名次和评价等级。多人监视依赖机器人的群主动消息权限。
