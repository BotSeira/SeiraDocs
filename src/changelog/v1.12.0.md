# 版本更新: v1.12.0

Seira 已经发布版本 `v1.12.0`，带来了一些新的功能和改进喵。

## 更新内容

### Miss 分析信息增强

现在 `/ma [score] #N` 的结果中包含了额外的PP信息：

```text
rlt. 260.70pp→248.38pp (-12.32)
fin. 282.25pp→270.97pp (-11.29 of -53.12)
```

其中， `rlt.` 一行为实时计算的 PP 损失，即游戏中实时 PP 计数器因对应 Miss 发生而减少的 PP 量。
`fin.` 一行为最终计算的 PP 损失，即在最终结算时，多出的这一个 Miss 导致的 PP 减少量。
因为 PP 算法仅关注判定结果数量，所以若有多个 Miss，其 `fin.` 的值应该相同。

### `/s` 功能增强

`/s` 现在可以查询指定玩家在指定谱面，使用可选的指定Mod的成绩。完整语法如下：

```text
/s m1234567 @someone +HDDT
```

其中每个参数均可以省略。

### 优化指令目标记忆功能

现在在使用部分需要指定目标的指令时，可以自动获取上一条指令所指定的目标而无需再额外指定。例如：

```text
/rp           (获取最近通过的成绩 X)
/sa           (获取 X 的成绩分析)
/r 1:30-2:00  (渲染 X 的回放)
/ma #1        (获取 X 的第一个 Miss 的分析)
```

### 更新与优化了 `/rg`

`/rg` 现在支持更多子指令：

- `/rg wish [bpN]`： 许愿
- `/rg stats [all/@someone]`：查询战绩
- `/rg lb [M-N/all/global [M-N]]`：查询排行榜
- `/rg weight [@someone]`：查询权重

同时，基于用户反馈，也对部分机制和算法进行了调整。
详情可见 [文档网站](https://docs.seira.top/commands/fun.html#rg)~

### 添加了 `/rcancel` 指令

添加了新指令 `/rcancel`，用于取消目标回放渲染。 当回放渲染卡死时，可以使用此指令来取消渲染。
指令可以通过回放渲染发起者手动点击回复的 `取消渲染` 消息按钮来进行调用。

### 添加了 `/f @user` / `/mu @user`

添加指令 `/mu @user`，用于查询自己和指定用户绑定的玩家的好友关系。
点击回复中的玩家名可以快速打开对应玩家的玩家主页。

也可以使用 `/f @user` 来查询好友关系。

### 添加 `/sup [@user]` 指令

添加了 `/sup [@user]` 指令，用于查询指定用户的支持者状态。


### 部分图片布局优化调整

调整了部分结果图片的布局排版。
